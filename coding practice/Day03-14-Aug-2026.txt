Day 03 - Ansible, Terraform & Kubernetes Basics
   Ansible - Install Apache and Start service
- name: Install and Start Apache
  hosts :all
  become: yes
  tasks:
   - name: Install apache
     yum:
       name: httpd
       state: present

   - name: Start apache
     service:
       name: httpd
       state: started
       enaled: yes

Kubernetes - Create a Replicaset with 3 Replicas
apiVersion: app/v1
kind: Replicaset
metadata:
  name: pathnex-replicaset
space:
   replicas: 3
   selector:
     matchLabels:
       app: pathnex-app
   template:
     metadata:
       labels:
         app: pathnex-app
     spec:
       containers:
         - name: app
           image: nginx
           ports:
            - containerport: 80
